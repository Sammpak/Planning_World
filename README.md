# Planning World

Planning World is a task management web application developed as a project during my studies in 2023.

It allows teams to organize their work, manage multiple projects, and track tasks through different workflow stages, such as **To Do** and **In Progress**.

## Features

* **Task Management** - Create, organize, and track tasks.
* **Project Management** - Manage multiple projects in one place.
* **Team Collaboration** - Organize tasks and collaborate with your team.
* **Task Statuses** - Move tasks between different workflow stages.
* **User Authentication** - Create an account with basic security measures.
